# ATLAS_AI

### Making Space Knowledge More Accessible

ATLAS_AI is a Python-based desktop assistant developed with the goal of helping space enthusiasts access reliable information more easily.

The project aims to make knowledge about space and astronomy more accessible through a simple, interactive, and user-friendly experience.

---

## 🌌 About the Project

ATLAS_AI was created out of a passion for space and the desire to make reliable information easier to access.

Its primary purpose is to provide users with an accessible assistant through which they can explore topics related to space and astronomy.

ATLAS_AI is an independent personal software project, developed and maintained independently.

## ✨ Features

- **Interactive Conversations:** Communicate with the assistant through a conversational interface.
- **Space & Astronomy:** Explore information related to astronomy and space.
- **Conversation History:** Maintain conversation continuity through saved chat history.
- **Local Data Management:** Use local JSON files for application data and configuration.
- **Desktop Application:** Run ATLAS_AI as a standalone Windows application.

## 📥 Installation

### Windows Executable

1. Visit the [Releases](../../releases) section.
2. Download the latest available release.
3. Extract the downloaded archive.
4. Keep the required application files and folders together.
5. Run `ATLAS_AI.exe`.

**Important:** Do not separate or delete required files such as `server.json` or the `assets` folder. The application may need them to operate correctly.

## 📁 Project Files

The distribution package may contain:
- `assets/` - The files about ATLAS AI.
- `build/` - This is necessary for doing .exe.
- `dist/` - This is necessary for doing .exe.
- `ATLAS_AI.py` - ATLAS AI's Python file.
- `ATLAS_AI.spec` - ATLAS AI's spec file.
- `ATLAS_AI.exe` – Main application.
- `server.json` – Application data and configuration.
- `gokatlasico` - The last one, it is ATLAS AI's logo.
